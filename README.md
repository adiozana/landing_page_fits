# FITS — Your Personal Style, Effortlessly

דף נחיתה לאפליקציית **FITS**, אפליקציית סגנון אישי המסייעת למשתמשים לגלות ולבנות את הלוק המושלם עבורם בקלות.

🔗 **דף הנחיתה החי:** [landing-page-fits-six.vercel.app](https://landing-page-fits-six.vercel.app/)
🎨 **פרוטוטייפ בפיגמה:** [Figma Prototype](https://www.figma.com/proto/afwXAlx0vPuE54zyjMUmn8/FITS-PROJECT?node-id=2-902&t=92rIeY325cXg4t6T-1)
🎬 **סרטון הצגת הפרויקט:** [YouTube](https://youtu.be/5IaaoqN2Das)

## על הפרויקט

דף הנחיתה מציג את הרעיון של FITS, כולל וידאו הדגמה של האפליקציה בתוך מסגרת iPhone, ומהווה נקודת כניסה למעבר לפרוטוטייפ האינטראקטיבי בפיגמה.

## טכנולוגיות

- HTML5 / CSS3 (עמוד סטטי בקובץ יחיד)
- פריסה (Deployment) באמצעות [Vercel](https://vercel.com/)

## הרצה מקומית

הפרויקט הוא עמוד HTML סטטי, ניתן להריץ אותו פשוט על ידי פתיחת `index.html` בדפדפן, או באמצעות שרת סטטי מקומי:

```bash
npx serve .
```

## מבנה הפרויקט

```
.
├── index.html      # דף הנחיתה
├── fits_demo.mp4   # וידאו הדגמה המוטמע בעמוד
└── vercel.json     # קונפיגורציית פריסה ל-Vercel
```
