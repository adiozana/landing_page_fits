# FITS — Your Personal Style, Effortlessly

> Dress well, every single day.

**FITS** היא אפליקציית סטיילינג אישי המרכיבה עבור המשתמש תלבושות שלמות ומותאמות — לפי המידות, הטעם והאירוע שלו — ומאפשרת לרכוש את כל הלוק ממותגים שונים בעגלת קניות אחת. הריפו הזה מכיל את **דף הנחיתה** של הפרויקט.

🔗 **דף הנחיתה החי:** [landing-page-fits-six.vercel.app](https://landing-page-fits-six.vercel.app/)
🎨 **פרוטוטייפ אינטראקטיבי בפיגמה:** [Figma Prototype](https://www.figma.com/proto/afwXAlx0vPuE54zyjMUmn8/FITS-PROJECT?node-id=2-902&t=92rIeY325cXg4t6T-1)

## הרעיון

> "You shouldn't have to think about what to wear."

FITS משלבת את העדפות הגרדרובה, מידות הגוף והסטייל האישי של המשתמש כדי להרכיב תלבושות שלמות וזמינות לרכישה. ניתן לשלב פריטים ממותגים שונים, להחליף כל פריט בלחיצה אחת, ולשלם על הלוק כולו במקום אחד — בלי לקפוץ בין אתרים, בלי בלגן.

## איך זה עובד

הדף מציג תהליך בן 4 שלבים:

1. **בניית פרופיל** — שאלון סטייל קצר: מידות, טעם אישי, וסוגי האירועים שעבורם המשתמש מתלבש. ניתן ליצור פרופילים לכל בני המשפחה.
2. **חיפוש לפי אירוע** — המשתמש מתאר מה הוא צריך (ראיון עבודה, ארוחת בראנץ', לוק חורפי לסופ"ש), וה-FITS מבינה את ההקשר.
3. **חידוד הלוק** — החלפת פריטים בודדים, שינוי שכבות, או בקשת תלבושת חדשה לגמרי, עד שהלוק מדויק.
4. **קנייה של הלוק כולו** — פריטים ממותגים שונים, בעגלה אחת, בלי לחפש בטאבים נפרדים.

## מה מייחד את FITS

| תכונה | תיאור |
|---|---|
| **פרסונליזציה אמיתית** | המערכת לומדת מידות, מותגים מועדפים, השראות סטייל ותקציב — כל המלצה מסוננת לפי ההקשר האישי, לא טרנדים גנריים. |
| **עגלה אחת, מותגים רבים** | קנייה מ-H&M, Zara, ASOS, Mango וכו' בצ'קאאוט יחיד — FITS מטפלת במורכבות ה-cross-brand. |
| **קנייה למשפחה כולה** | פרופילי משנה לילדים, בן/בת זוג או הורים, כל אחד עם תלבושות מותאמות אישית, הכל מחשבון אחד. |
| **לוקים שלמים, אפס מאמץ** | FITS מרכיבה תלבושת שלמה (חולצה, מכנס, נעליים, תיק) ללוק אחיד וקוהרנטי, מוכן לרכישה. |

## למי זה מיועד

- **אוהב/ת הקניות** — נהנה/ית לגלוש, לגלות מותגים ולבנות גרדרובה. FITS הופכת את חוש האופנה שלך ללוקים שלמים ומתואמים, מוכנים לקנייה.
- **הקונה המתוסכל/ת** — הגרדרובה מלאה אבל שום דבר לא מתאים. FITS מגשרת בין פריטים בודדים שאהובים עליך לבין תלבושות שבאמת עובדות ביחד.

## טכנולוגיות

- HTML5 / CSS3 — עמוד סטטי בקובץ יחיד, כולל אנימציות scroll-reveal ואיורי SVG מותאמים
- וידאו הדגמה (`fits_demo.mp4`) המוטמע במסגרת iPhone בהירו
- פריסה (Deployment) באמצעות [Vercel](https://vercel.com/), עם `vercel.json` לניתוב SPA

## הרצה מקומית

הפרויקט הוא עמוד HTML סטטי. ניתן לפתוח את `index.html` ישירות בדפדפן, או להריץ שרת סטטי מקומי:

```bash
npx serve .
```
